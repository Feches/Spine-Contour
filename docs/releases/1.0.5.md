# Spine Contour 1.0.5

Manual image calibration now survives app restarts even when applied before the
images are loaded as studies. Segmentation reuses the saved reference for that
image, and anterior, middle and posterior disc heights and exports use its scale.

## Calibrating an image manually

1. Open **Image calibration** and choose the image.
2. Click **Draw reference**, then place the two endpoints of a known length.
3. Enter that length in millimetres and click **Apply reference**.
4. Wait for **Reference saved for this image**, then continue to segmentation.

The reference is tied to the original image contents. An unchanged image can be
renamed or moved without losing its reference; a different image does not inherit
it merely because it has the same filename. Windows drive/path case and separator
differences also resolve to the matching loaded study.

Changing and applying a reference after segmentation updates disc heights without
another model run. **Clear scale** saves an explicit clear for that image; unknown
heights remain blank. Save failures are shown in the calibration panel instead of
being reported as successful saves.

## Installation

The release provides Windows x64 and macOS Apple Silicon installers plus
`SHA256SUMS`. In-app updating is not included; install the new version over the
existing app. Studies and settings remain in the existing application profile.
The macOS app remains unsigned.
