# Spine Contour v1.0.4

## Toolbar removal

Open **Settings → Processing → Toolbar removal → On** to remove detected bottom
PACS toolbars from screenshots before segmentation. This fast OpenCV step is
independent of Crop localizer and applies to single images and batches in both
Standard and Low memory modes. The choice is saved across launches and starts Off.

Only a thin bottom panel with a strong boundary, flat starting rows, a mostly
uniform background and distributed small text/button-like shapes is removed.
Uncertain cases, top/side panels and native high-bit-depth/DICOM images stay
unchanged. Other PACS designs may require leaving this setting Off.

The processed image and segmentation overlays exclude the detected strip. The
source file and calibration reference remain intact. Removing only bottom rows
preserves the original x/y origin and pixel spacing. Processing reports the
detected strip height and stores cleanup details with the result. Existing saved
results change only when reprocessed.

This cleanup does not replace the lumbar-region search on full-spine images.
For lumbar-only inputs, Crop localizer can still be turned Off for faster inference.
