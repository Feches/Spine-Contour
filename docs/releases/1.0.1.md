# Spine Contour v1.0.1

Fixes the all-or-nothing behavior on incomplete segmentations. Previously one
missing lumbar level, missing S1 or rejected femoral fit could discard the entire
image result. An L1-only detection now retains L1 for review and editing; measurements
that need other structures remain unavailable.

- Save and display every usable detected level without renumbering it. Mark partial
  results **Needs review** and list the missing structures.
- Compute sacral slope from S1, each lordosis from its level and S1, PI/PT from S1
  and the hip axis, and L1PA when L1 is also available. A femoral-fit rejection keeps
  independent spine measurements. Existing fit thresholds remain in force.
- Use the image extent when S1 cannot anchor the crop, trimming broad near-black
  screenshot margins while preserving original-image coordinates. HRNet's always-present
  slots require matching U-Net body-mask evidence before being retained, with
  invalid/off-film quadrilaterals excluded.
- Draw, pick and keyboard-cycle only existing landmarks. Partial corrections, reset,
  study reload and batch continuation preserve their geometry and missing values.
- Export available calibrated disc heights and supported per-visit changes. Missing
  anatomy stays blank; a missing level is never bridged to create a disc. Without an
  S1 orientation reference, U-Net endplates support midpoint heights but not named
  anterior/posterior heights. Null PI/LL values cannot turn into a numeric mismatch.
- Update the Documentation button to Cody's repository.

The Windows x64 and macOS Apple Silicon installers retain the bundled backend,
models, OpenCV and Tesseract. On merge, the release workflow builds both platforms
and publishes v1.0.1 with checksums; v1.0.0 remains unchanged. Existing complete
study libraries remain readable. Older app versions do not support saved partial
geometry, so use v1.0.1 or later to reopen these results.

The regression suite covers all 127 nonempty combinations of L1–L5, S1 and the hip
axis, API prediction/correction, viewer selections, persistence, batch eligibility
and CSV output. These are software checks, not a clinical accuracy validation.
Partial support preserves available detections; it does not establish that their
anatomical labels are correct. Films with no usable landmarks still report an error.
