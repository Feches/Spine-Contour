# Spine Contour 1.1.0

This release adds an optional fast film-type classifier for automatic view selection.

## Automatic view selection

- In **Settings → Automatic view selection**, choose **Fast classifier** to classify
  the whole film before segmentation. **Landmark search** remains the default.
- Use **Check film type…** to preview a film's classification and inference time.
- The classifier recognizes cervical lateral, lumbar lateral, full-spine lateral,
  lumbar AP, and a limited other-view class. AP/other predictions and low-confidence
  results ask for manual selection. AP cervical is not a trained class.
- Explicit region selections override automatic selection. Cervical anterior orientation
  still requires an explicit choice. Segmentation continues to use the existing models
  and crop search after a supported lateral view is selected.

The classifier is experimental and can make confident errors, particularly on partial
films or unfamiliar views. Review the selected region and resulting measurements.
See the [model card](../view-classifier.md) for evaluation results and limitations.

## Verification

The implementation passed 615 desktop tests and 77 focused backend tests. A real
held-out cervical film was classified and segmented in the desktop app, and its overlay
was visually inspected. These are software and integration checks, not clinical validation.
The release workflow builds and tests the Windows and macOS installers before publication.
