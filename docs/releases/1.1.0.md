# Spine Contour 1.1.0

This release replaces the landmark editor with a vertebral level editor, adds window / level to the stage, and
writes a per-film label record whose job is retraining the segmentation models.

## The level editor

- **Edit segmentation** turns the right panel into the Vertebral levels panel: sixteen levels in five groups
  (C2–C7, T1 · T4, L1–L5, S1, two femoral heads), each with a visibility checkbox, a state badge (Segmented, Edited,
  Manual, Not placed, Not visible) and Place… / CLEAR.
- A level the model missed is placed by clicks on the film: four corners for a body, three for C2, two for an
  endplate, one for T4, two to four rim points for a femoral head (FIT from two). The edit bar's step chips choose
  which point the next click sets, in any order; a placed chip re-places that point; UNDO removes the most recently
  set point. A head's click within 1 px of one of its rim points is ignored and no head can be fitted or dragged
  under 0.5 px.
- Only the selected level has handles; a drag or an arrow nudge commits through `/measure` as before, so the
  measurements and `studies.json` follow at once. RESET TO PREDICTION and Discard are in the edit bar and the panel.
- **Save edits** writes `labels/<stem>.label.json` in the app's data folder: every level's state and points in
  stored-image pixels, the model's original points for an edited level, the model's mask outline for a level still
  the model's, the image hash and size, the model version, an `edited_points` list per entry and an `edits` summary
  (counts per state, points moved, points placed). Window / level is never in the record. Leaving with unsaved
  level edits asks: Save, Discard or Keep editing.
- **Mark reviewed** writes the record for a film that has none yet (the zero-change record of the stored state), so
  an accepted prediction is labelled without entering edit mode. Unmarking writes nothing.
- A film with no result, or whose segmentation failed, opens in edit mode on its original film and can be placed by
  hand; an Auto film takes its region from the levels placed on it. Re-run and the Region and Orientation selects wait
  for edit mode to end.
- The old edit bar's RETRACE, ADD CIRCLE and DELETE CIRCLE are gone: a head is re-placed from the panel and FIT, and
  hidden with its checkbox.

## Window / level, zoom

- The toolbar's window / level button opens a panel (WIDTH and LEVEL sliders, RESET, DONE) in and out of edit mode.
  The original film is decoded through the backend's new `POST /decode` (16-bit DICOM values with rescale applied,
  the DICOM window as the default) and a linear lookup table is applied to the film layer only. Display only: nothing
  is saved and the record never changes.
- A right-button drag windows the film without the panel (left–right width, up–down level); a double right-click
  resets to the film's default. The window stays while the film is open, like zoom and pan.
- Zoom reaches 800%. Past one screen pixel per image pixel the overlay magnifies with the film instead of fading.

## Backend

- `POST /decode` returns the uploaded film's own pixel values and window defaults.
- `qc.model_versions` names the graph that read each structure, so a stored result and its label record say which
  model produced them.

## Compatibility

The store format is unchanged. Label records are new files beside `studies.json` and `predictions/`; a study's record
is deleted and quarantined with it. The macOS build remains unsigned.
