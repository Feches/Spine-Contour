# Spine Contour 1.0.12

The Workspace's column-mapping card can now import a spreadsheet column the app does not
know under the column's own name. Nothing else changes in this release: no model,
measurement, export-format or processing change, and the model weights are unchanged from
1.0.11.

## Keeping a column under its own name

When a workspace CSV is chosen, each column gets a chip with a dropdown. The nine known
clinical fields auto-map by prefix as before; any other column used to stay unmapped
unless it was pointed at one of the known fields. Each chip's dropdown now also offers
**Keep column name (the header)**, which imports that column as a custom clinical field
named after its header, trimmed of surrounding spaces. A kept column then behaves like any
mapped one: Load workspace attaches its values to the matched studies, the Parameters
table lists it after the known fields, and both CSV exports carry it.

The option is not offered when the header names a known field (map it to that field
instead) or is already another column's destination. The `study_id` join key and the four
study-detail columns (`subject_id`, `timepoint`, `film_date`, `view` and their aliases)
have no dropdown and are never kept.

**Keep N unmapped columns**, at the head of the card, keeps every remaining unmapped
column at once and appears only while there is something to keep. For each unmapped
column: a header whose name is a free known field maps to that field rather than to a
custom copy (`diagnosis_text` maps to Diagnosis); an empty name, a reserved column, or a
name already used as another column's destination is left unmapped. The help text beside
the button is a reminder that an unknown column can be an identifier: check the names
before keeping everything. The row's **Set all…** dropdown offers **Unmapped**, which
clears every mapping, kept and known alike, so the card can be started over.

This is one feature lifted on its own from the similar-cases work still in progress;
nothing else from that work is included.

## Checks

The renderer unit tests pass on this tree (582, including two new tests for the bulk
action and the version label). The mapping card was walked by hand on 2026-09-14 on the
branch the feature came from, where the surrounding card code is identical; it was not
walked again from source on this tree.

## Installation

The release provides Windows x64 and macOS Apple Silicon installers plus
`SHA256SUMS`. In-app updating is not included; install the new version over the
existing app. Studies and settings remain in the existing application profile.
The macOS app remains unsigned.
