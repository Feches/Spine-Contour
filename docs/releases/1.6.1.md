# Spine Contour 1.6.1

This release carries PR #79, one fix to 1.6.0: on a full-spine film the lumbar crops keep L1's superior endplate in
view again. The models, the decoders and every other path are unchanged.

## Lumbar crops on full-spine films

- To read the lumbar spine on a full-spine film, the search tries seven crops around the region it located (small
  shifts and scale changes) and keeps the ones the models agree on. 1.5.0 read the lumbar measurements from crops
  extended upward by 15% of their height, so that L1 stays inside them. 1.6.0 went back to 1.4.0's pipeline without
  that margin, and some crops cut off L1's superior endplate, which gave large lordosis errors.
- Now every crop is extended upward by 15% of its height before the models read it; its sides and bottom stay where
  they were, and the extension stops at the top of the film. The unextended crops are no longer tried.
- The same search runs when Auto detect classifies a film, so its orientation evidence comes from the extended crops
  too. A lumbar-only film is read by a different search and is unchanged from 1.6.0.
- A film segmented by 1.6.0 keeps its result until it is run again.

## Verification

1,258 desktop tests on the merged tree, unchanged from 1.6.0 (no desktop code changes). The merged tree is identical to
PR #79's head, whose Windows and macOS checks passed: both release builds, each running the backend and renderer
suites and verifying the packaged models. PR #79 replaces one backend test with two (the seven extended crops of a
sample window, and the extension stopping at the top of the film without moving the bottom) and reports 104 targeted
backend tests passing. On 99 real full-spine films, with four human readers and the same automatic localization, orientation and
cervical predictions before and after, it reports:

| Measure | 1.6.0 | 1.6.1 |
| --- | --- | --- |
| L1–S1 lordosis, mean disagreement with readers (same 93 films) | 6.29° | 4.49° |
| Films with L1–S1 lordosis | 93 of 99 | 97 of 99 |
| Films with all seven measurements | 83 of 99 | 87 of 99 |
| Global SVA, mean disagreement with readers (same 76 films) | 3.15 mm | 3.30 mm |

The cohort has been used in earlier evaluations, and the comparison checks the crop change, not the whole automatic
run from a fresh start; some landmark outliers remain. The smoke suites and a Windows GPU run were not done. These are
software checks, not clinical validation. The release workflow runs the backend and renderer suites and builds and
verifies the Windows and macOS installers before publication; merging the release PR to `main` publishes v1.6.1.

## Compatibility

No change to the study record, the label record, the CSV exports or the bundles. A library written by 1.6.0 loads
unchanged, and the other way round. The macOS build remains unsigned.
