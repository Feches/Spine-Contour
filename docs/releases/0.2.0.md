# Spine Contour v0.2.0 preview

This preview bundles Cody's batch/studies workflow with automatic image calibration,
calibrated disc-height exports and measurement accuracy safeguards.

- **Automatic calibration:** OpenCV/Tesseract extracts printed ruler lengths and
  endpoints from each original image. DICOM pixel spacing is supported. Each study
  retains its own scale; manual corrections survive reruns and restarts. Missing or
  uncertain references leave physical measurements blank while segmentation continues.
- **Disc heights:** anterior, middle and posterior heights for L1–L2 through L5–S1
  appear in Measurements and ordinary/paired CSV exports. Anterior/posterior heights
  connect matching keypoints across the facing endplates. Middle height connects
  their midpoints. Each film's scale is applied before paired changes are calculated.
- **Landmark review:** weak S1/crop detections trigger Needs review, independently of
  femoral fit and angular consistency.
- **Reliable corrections:** corrected geometry and recalculated measurements save
  together. Pending or failed edits retain the last complete saved result.
- **Input safeguards:** unsupported view labels are excluded from inference, and
  native 16-bit/float image intensities reach preprocessing without 8-bit clipping.

CSV exports add 15 disc-height columns after the angular measurements and before
clinical fields. Read columns by header name when updating analysis scripts. Missing
scale or invalid endplates produce empty cells, never invented zero measurements.

The Windows preview installer and macOS Apple Silicon disk image bundle the local
Python backend, model weights, OpenCV and Tesseract. The macOS build is unsigned.
Existing preview study libraries remain readable; the store version is unchanged.

Investigational software; not for clinical use. Landmark accuracy still requires
review. Unknown radiographic magnification, image-based view classification,
unequal-spacing angular correction and slip measurements remain outside this release.
