# Spine Contour 1.0.14

This release changes the welcome screen and the CSV exports. The authors' names are
removed from both (the exports now have two comment lines, not three), and ticking the acknowledgement no longer makes the logo blink out
and fade back in. Models, measurements and processing are unchanged from 1.0.13.

## Welcome screen

The CREATED BY card, which listed the two authors and their affiliations, is gone. The
panel now reads, in order:

- the RESEARCH USE ONLY label and the heading **Not for diagnostic or clinical use.**;
- the two paragraphs on investigational use and open release, as before;
- the contact paragraph, now set as body text, with the address
  spine-contour@gmail.com as a link that opens your mail app;
- the title of the methods paper, *spine-contour: An Open Source Platform for Automated
  Spine Segmentation and Spinopelvic Parameter Measurement*, marked
  (METHODS PAPER · FORTHCOMING).

The acknowledgement checkbox and **Enter SpineContour** follow as before.

## Logo on the welcome screen

Ticking or unticking the acknowledgement used to rebuild the whole welcome screen. The
rebuilt logo then replayed its entrance, so it disappeared and faded back in on every
click. The checkbox and **Enter SpineContour** now update in place. The logo plays its
entrance once, when the screen opens, and keyboard focus and the panel's scroll position
stay where they were.

## CSV exports

Both exports, **Export CSV** and **Export paired CSV**, used to open with three `#`
comment lines, the second naming the authors. That line is removed, so the file now
opens with two:

```
# Spine Contour export
# Investigational software. NOT FOR CLINICAL USE.
```

The header follows on the third line instead of the fourth. A reader that skips comment
lines (`comment.char = "#"` in R's `read.csv`, `comment = "#"` in pandas) is unaffected. A script
that skips a fixed three lines must now skip two, or it will drop the header. Columns and
values are unchanged.

## Checks

The renderer unit tests pass on this tree: 587, with every CSV test that reads a line by
its position moved up one. A new smoke check, `tools/smoke/smoke-landing.mjs`, drives the welcome
screen in the running app with real clicks. It covers the panel's text, the checkbox and
**Enter SpineContour**, and confirms the logo is the same element with no entrance running
after each click. It passed 16 of 16 checks, against 9 of 16 before the fix: 40 ms after a
click, the old logo was a new element at 7% opacity. The welcome screen was also checked
by screenshot in light and dark themes.

## Installation

The release provides Windows x64 and macOS Apple Silicon installers plus
`SHA256SUMS`. In-app updating is not included; install the new version over the
existing app. Studies and settings remain in the existing application profile.
The macOS app remains unsigned.
