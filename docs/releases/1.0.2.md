# Spine Contour v1.0.2

## Slower computers and processing progress

- Select **Settings → Processing → Low memory** to process search regions one at a
  time, keep one model loaded at a time and limit CPU threads. Settings survive restart.
- Low-memory mode keeps the full anatomical search and model resolution. It trades
  processing time for reduced peak memory; it is not a compressed or retrained model.
- See actual stages, search regions checked, calibration OCR passes and elapsed time.
  Healthy long runs stay connected through backend heartbeats.
- Cancel the current image and stop its batch, or use the batch **Stop** button to
  finish the current image first. Completed studies and previous re-run results remain.
- Give backend startup up to ten minutes and low-memory OCR up to sixty seconds per pass.

Partial-segmentation support from v1.0.1 is retained, including images without usable
femoral heads. Unsupported measurements remain blank.

Both Windows x64 and macOS Apple Silicon installers are built and verified before
the numbered release is published. These changes do not update an existing v1.0.1
installation in place; install v1.0.2 after release.

See [processing modes and validation](../low-memory-processing.md) for resource
policy, cancellation boundaries and validation details.
