# Spine Contour 1.0.18

Missed vertebrae can be annotated in the existing viewer. Open **Edit landmarks**, choose a missing level, and select **Add landmarks**. Click the named anatomical corners in the prompted order, review the preview, and select **Apply landmarks**. **Undo point** (Backspace or ⌘/Ctrl+Z) removes the last placement; **Cancel** or Escape discards the preview.

The control supports C2 inferior endplate, C3–C7 and L1–L5 vertebral bodies, S1 superior endplate, C2 body centroid, and the C7 body centroid in full-spine mode. It offers only missing points for the current region and preserves existing landmarks. Completed placements enter the standard measurement and save workflow; measurements remain unchanged until recalculation succeeds. Added landmarks can then be dragged like model landmarks, and Reset to prediction restores the model result.

The viewer layout, segmentation models, and measurement definitions are unchanged. A segmentation result and loaded radiograph are required to enter landmark editing.
