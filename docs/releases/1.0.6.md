# Spine Contour 1.0.6

The Find tab's studies table now supports reviewing, sorting, in-place subject edits and
a selective delete, so a whole workspace can be checked and corrected from the list
instead of opening every study. This release also includes 1.0.4 and 1.0.5's changes
unchanged.

## Reviewing a study

Open a segmented study and click **Mark reviewed** next to Export CSV on the Analysis
screen. The button reads **Reviewed · <date>** and the study's status, on the Analysis
header and on the Find list, changes from Needs review or Segmented to **Reviewed**.
Click it again to unmark.

The mark is cleared automatically whenever the measurements it was set over are
replaced: a re-run of segmentation, a landmark correction, **RESET TO PREDICTION**, or a
change to the image's calibration. A subject, timepoint, film date or view edit leaves
the mark alone. The quality warnings in the Measurements panel stay visible on a
reviewed study; they describe the segmentation, not an outstanding task. The Reviewed
mark is not included in the CSV exports.

## Editing subjects on the list

Click the SUBJECT cell of any real study on the Find tab to open an editor pre-filled
with its current value. Press **Enter** to commit and open the next row's SUBJECT cell,
so a whole column can be corrected without leaving the keyboard. **Tab** and **Shift+Tab**
commit and move focus normally; **Escape** discards the edit and restores the stored
value. Demo studies are not editable.

## Deleting selected studies

Tick the studies to remove, on either the Find tab or the Parameters tab — the two share
the same selection. The Find tab's filter bar shows **Delete N selected**; clicking it
asks for confirmation and explains that the saved results are removed but the original
image files are kept. Only the ticked studies that are currently visible are deleted: a
study hidden by the search box or by the Workspace/Folder filters is never touched, even
if it is ticked. This replaces the earlier library-wide "Delete all studies" button.

## Sorting

Every column header on the Find tab — Study, Subject, View, Workspace, Folder, Date and
Status — is now a sort control, matching the Parameters grid. Studies show newest first
by default; clicking a header sorts by that column, and clicking it again reverses the
direction.

## Demo studies

Settings gains a Show/Hide switch for the nine built-in demo studies. It appears only in
development builds; installed applications never show demo studies and never offer this
switch.

## Installation

The release provides Windows x64 and macOS Apple Silicon installers plus
`SHA256SUMS`. In-app updating is not included; install the new version over the
existing app. Studies and settings remain in the existing application profile.
The macOS app remains unsigned.
