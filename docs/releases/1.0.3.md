# Spine Contour v1.0.3

## Inference and image framing

- Add **Settings → Processing → Crop localizer**. Keep it On for full-spine
  images. Turn it Off for lumbar-only images already framed around the anatomy
  to skip crop search and reframing. This is saved for single runs and batches.
- Run the existing vertebra U-Net, femoral U-Net, S1 detector and HRNet through
  ONNX Runtime. Keep the trained float32 weights and 768 × 768 model resolution.
- Avoid calculating S1 keypoints for lower-scoring boxes the app never uses.
- Use Apple's CPU acceleration for the S1 detector in Standard mode, with ONNX
  CPU fallback. Low memory uses explicitly limited CPU threads and one model
  session at a time. Windows uses ONNX's CPU provider without extra GPU drivers.
- Build-time model conversion and parity checks, plus actual inference checks in
  the frozen backend, protect both Windows and macOS installers. Training
  libraries and duplicate PyTorch weights are no longer included in installers.

Partial anatomy, missing femoral heads, calibration, disc-height exports, real
progress and cancellation remain supported. Disabling localization changes the
model input; use it only for appropriately framed lumbar images and review results.

Both installer builds must pass before merging can publish v1.0.3. Existing
installations require installing the new release; no model download is needed
at first run. See [implementation and validation](../onnx-inference.md).
