# T4 centroid kept and drawn, T4 pelvic angle, T1 slope — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a placed T1 endplate and T4 centroid reach the study, draw outside edit mode, and read as the T1 slope and the
T4 pelvic angle in the panel, the grid and both CSV exports.

**Architecture:** the backend computes both angles in a new pure module applied by the `/measure` handler on every
region path (the lumbar path echoes the two new geometry fields it used to drop); the renderer's projection writes
`t1_superior` and `t4_centroid` on every region and reads them back; the display reads the stored backend values
through the existing row, column and construction tables, each gaining one entry per measurement.

**Tech Stack:** Python/FastAPI + numpy (backend), vanilla ES modules (renderer), `node --test`, pytest, the CDP smoke
harness in `tools/smoke/`.

**Spec:** `docs/superpowers/specs/2026-10-22-t4pa-t1-slope-design.md` (O1–O3 the owner; P1–P16 the planner). Fact sheet
with line numbers: `.superpowers/sdd/2026-10-22-t4pa-t1-slope/fact-sheet.md` (at `5ec39d7`; the branch is now past
`ac6a641`, a backend fix that did not move these lines).

  `float(min(abs(deg), 180 - abs(deg)))` of `atan2(dy, dx)` over `p[1] - p[0]`.
- Produces: `t4_pelvic_angle_degrees(t4_centroid, hip_midpoint, s1_superior) -> float | None` — the centroid None →
  None; a finite (2,) else ValueError("T4 centroid must be one finite image point"); hip or S1 None → None; S1 midpoint
  = the pair's mean; `v1 = t4 - hip`, `v2 = s1_mid - hip`; either zero-length → None; else
  `degrees(atan2(abs(v1[0]*v2[1] - v1[1]*v2[0]), dot(v1, v2)))`.
- Produces: `thoracic_measurements(request_geometry: dict, measured_geometry: dict) -> dict` =
  `{"measurements": {"T1S": ..., "T4PA": ...}, "geometry": {"t1_superior": list | None, "t4_centroid": list | None}}`,
  reading `t1_superior`/`t4_centroid` from the request (absent = None) and `hip_midpoint`/`s1_superior` from the
  measured geometry; the echoed fields are `.tolist()` copies of the validated arrays.
- Produces, in server.py: `_with_thoracic(request: dict, result: dict) -> dict` (module-private) that merges both
  dicts of `thoracic_measurements(request, result["geometry"])` into `result["measurements"]` and `result["geometry"]`
  and returns `result`.
