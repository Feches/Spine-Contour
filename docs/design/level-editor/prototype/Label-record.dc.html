TRAINING DATA · ONE FILE PER FILM

Segmentation label record

Save edits writes this record beside the study. It keeps what the annotator asserted for every level, and the model’s original output wherever it was corrected, so retraining can tell a fixed level from one nobody looked at.

How retraining reads each state

STATE MEANING TRAINING USE
Segmentedsegmented
 Model output, accepted unchanged. Positive label
Editededited
 Model output corrected by hand. model_corners keeps the original. Positive label · error pair
Manualmanual
 Placed by hand where the model found nothing. Positive label · missed level
Not visiblenot_visible
 The annotator says the level isn’t on the film. Negative label
Not placednot_placed
 Visible, but nobody placed it. Ignored · film incomplete

Fields

FIELD CONTENT
image.sha256 Hash of the pixel data. Ties the record to the exact image without a name or record id.
film.region · film.view The film type. Sets which groups start expected visible.
model.name · model.version The model whose output was reviewed.
levels.*.corners SA, SP, IA and IP in image pixels from the top-left. T1 and S1 hold only the anterior (sa) and posterior (sp) corners of the superior endplate.
levels.T4.centroid One point, [x, y], in image pixels. T4 has no corners.
levels.*.model_corners The model’s corners when the level was edited; null otherwise.
levels.*.contour Outline in image pixels; null when only corners exist.
levels.*.source Who set the state: model, annotator or film_type.
femoral_heads[] Centre and radius in image pixels, fitted from the 2–4 points in rim (two points are read as a diameter). rim is null for unedited model output. Same state and source as a level.
complete True when no level is not_placed.
